# Getting help with NOOP Forge

NOOP Forge is a free project built in spare time, an independent fork of
[ryanbr/noop](https://github.com/ryanbr/noop). There is no company behind it and no paid support. The
[FAQ](docs/FAQ.md#help-bug-reports-and-support) explains the channels below in more detail.

- **❓ First stop → the [FAQ](docs/FAQ.md)** and the wiki's
  [Troubleshooting](https://github.com/DX23876/noop/wiki/Troubleshooting) (pairing, sync, "no data")
  and [WHOOP 5.0 / MG status](https://github.com/DX23876/noop/wiki/WHOOP-5.0-and-MG-Status) pages.
  Most questions are answered there.
- **💬 Questions, setup help, "is this normal?" → [Discord](https://discord.com/invite/wKgyqVdjrP)** or
  [GitHub Discussions](https://github.com/DX23876/noop/discussions).
- **💡 Ideas and feature requests → [GitHub Discussions](https://github.com/DX23876/noop/discussions).**
- **🐞 A confirmed bug → a [GitHub issue](https://github.com/DX23876/noop/issues/new/choose)** with the
  bug template (Android testing builds have their own form). Search the
  [existing issues](https://github.com/DX23876/noop/issues?q=is%3Aissue) first. Include the **NOOP
  version**, **platform** and **strap model**, plus a **strap log**: NOOP runs entirely on your device,
  so without one a real fault usually cannot be told apart from a setup detail.
  - iPhone, iPad and Mac: Settings → **Connection diagnostics** → *Strap log* → **Save…** or **Copy**
  - Android testing builds: Settings → **Help & Diagnostics** → **Share strap log**

  A bug reported only on Discord tends to get lost; an issue is tracked until it is fixed.
- **🔒 A security problem → do not open a public issue.** Follow [SECURITY.md](SECURITY.md).
- **📖 Docs → the [README](README.md)** covers install (AltStore/SideStore on iPhone, macOS Gatekeeper,
  the Android testing APK), privacy and importing your history. Android testers:
  [docs/fork/android/TESTING.md](docs/fork/android/TESTING.md).
- **☕ Support the project → [Ko-fi](https://ko-fi.com/dx23876).** Optional; the app is the same either
  way.

Using ryanbr's original NOOP rather than this fork? Its own channels are listed in
[its repository](https://github.com/ryanbr/noop).

NOOP Forge is an independent, unofficial project, **not affiliated with WHOOP, Inc.**, and **not a
medical device**.
