# NOOP Forge 12.2.0

A training release on top of 12.1.2. NOOP Forge is an independent fork of NOOP by ryanbr, not the
official app. Bundle identifiers, the App Group and the store path are unchanged, so an installed app
keeps its data, Health permissions and AltStore update path.

## The running logger

- **Typed numbers.** Weight and repetitions are typed on the number pad instead of tapped up and down
  with plus and minus buttons, which VoiceOver still offers as the adjustable action. The bar over the
  pad carries the plate calculator while a weight is typed.
- **Last session beside each set.** A previous column shows the matching working set of the last
  session; tapping it copies its numbers. Prefilled values read grey until you type, copy or complete
  them.
- **A slimmer header.** Duration, volume, completed sets and, with a source, live heart rate sit in one
  row, so the sets start higher on the screen. Volume counts completed working sets with a load.
- **All exercises by default.** The logger opens on the list of all exercises and brings the next one
  up when an exercise is finished, except between the exercises of one superset.
- **Rest per exercise.** A rest chip on each exercise sets its rest on a wheel for the rest of the
  session. The note is written in its own sheet and shown under the exercise title.
- **Set numbers as on a gym sheet.** Warm-ups read "W" and working sets count from one. A drop or
  rest-pause segment takes no number of its own and now sits right after its set instead of at the end
  of the exercise. The effort column is named RPE or RIR after the scale you use.
- **Adding and removing sets.** Every exercise card has an Add set button, also once the exercise is
  done. A set goes by swiping its row to the left. An exercise added without history starts with three
  working sets; Settings › Training changes the number from one to six.
- **Exercise media and details.** With the optional media pack, a still sits beside each exercise
  title and a tap opens the full demonstration. The exercise name opens the library's exercise page.
- **The end-of-rest buzz while typing.** The rest signal no longer goes missing when the rest runs out
  while a number is being typed.

## Lock Screen, Watch and strap

- **The next set on the Lock Screen.** The Live Activity names the next set, with its exercise and
  target, and logs it with one tap when the set already has its numbers. During a rest it offers
  −15, +15 and Skip. Once a rest runs out it shows the next set again; if iOS has suspended NOOP, the
  rest holds at zero until NOOP runs again.
- **One next set everywhere.** The logger, the Lock Screen, the Watch and the strap double-tap now pick
  the same next set. In a superset the Watch could complete a different set than the phone showed.
  The "no numbers yet" notices name the set as the logger does.

## Routine imports

- **Hevy routines.** Training › Add › Import Hevy routines brings in the routines of a connected Hevy
  account (Hevy Pro API key). Hevy's "Bench Press (Barbell)" is matched to NOOP's "Barbell Bench
  Press", and only an exercise NOOP does not know is added as a new one.
- **OpenGym plan files.** Training › Add › Import OpenGym plan reads the file OpenGym writes under
  Plan › Export plan file. Sets, repetition ranges, loads in kilograms or pounds, warm-ups, pyramids,
  drops, rest-pause, rest, supersets and notes carry over; the plan's week joins your schedule only
  when you switch it on. Progression rules and cardio slots stay out.
- Both show a preview where routines can be left out. Your own routines are never changed, and
  importing the same routine again updates the earlier copy instead of adding a second one.

## Exercise catalogue

- Four sled exercises read "Sled 45° Leg Press" and so on instead of a garbled "45в°" carried over
  from the source data.

Analysis migration required: no. Nothing in this release changes how values are computed.
