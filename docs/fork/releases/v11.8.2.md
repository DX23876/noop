# NOOP AI 11.8.2

A hotfix for 11.8.1. One bug in it made the app's main screen useless for anyone on the default
layout, so this release carries nothing else.

## Today drew nothing

On the Liquid Today — the default on both platforms — the screen could come up completely empty:
the tab bar rendered, the content area stayed blank, and taps in it did nothing. Every other tab
worked, and the data was never affected, which is exactly what made it look like a data problem
rather than a layout one.

The cause was two containers in the Today body that 11.8.1 had made lazy. The outer one begins with
three children that carry no height at all — a scroll-to-top anchor, an overscroll probe pinned to
zero, and the refresh indicator at rest — and a lazy container that finds only zero-height children
ahead of it can settle on zero content height and never build the stack that carries the screen.
Both are eager again, which is what they were before and what upstream still uses.

If you worked around this by switching to Classic, nothing forces you back: the setting is yours.
Liquid is simply usable again.

## An unfinished session that could not be finished

Starting a strength session and losing the app before completing a single set — a crash, iOS
reclaiming memory, a flat battery — left a draft behind. That is deliberate: the draft is what keeps
an interrupted session from vanishing. Four hours later the next launch asked what to do with it.

For a draft with no completed set, "Save" could never work: the engine refuses to complete a session
that logged nothing, and the draft was then kept so nothing would be lost. The question therefore
came back on every single launch, and only the destructive answer could end it. A session with
nothing logged now closes itself, and the prompt is reserved for one that holds actual work.

## Also

- The German button for throwing away an unfinished workout now reads "Verwerfen" rather than
  "Entsorgen", matching the wording its sibling dialog already used.

Analysis migration required: no. Nothing here changes a score, an input window, or the meaning of a
stored value; no rescore runs.
