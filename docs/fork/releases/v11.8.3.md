# NOOP AI 11.8.3

This release integrates the applicable Apple changes from RyanBR upstream while preserving the
Apple-only fork, its whole-tree localization gate, and its Coach and Today redesign.

## Reliability and honest readouts

- Interrupted background reanalysis is retried after its cooldown and paced in short CPU quanta.
- Charge details, confidence labels and Coach summaries use the same post-recalibration HRV history.
- Alarm screens distinguish the strap's actual wake alarm from the evening reminder and show the
  countdown to the next buzz.
- A still-growing detected night and its vitals are held out of Apple Health until the night closes.
- Oura authentication retries an unanswered nonce within a bounded watchdog, and the Live console
  reports the ring's actual connection phase.
- Strap rename diagnostics no longer print the user-chosen Bluetooth name.

## Lab Book continuity

Custom count and percentage rows such as `LYMPH` and `LYMPH %` now receive distinct keys. On upgrade,
the versioned migration identifies legacy custom rows whose stored unit is explicitly percent, moves
them to the percentage key, rebuilds their daily projections in the same transaction, and advances its
cursor only after success. Count rows, user-entered readings, sleep/workout corrections and raw samples
are not erased.

Analysis migration required: yes. Recipe 8 performs the Lab Book key migration and then runs the
resumable bounded 21-day analysis pass so recent consumers of the old projected key are refreshed.
