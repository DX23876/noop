# NOOP Forge 12.1.2

A fix release on top of 12.1.1. NOOP Forge is an independent fork of NOOP by ryanbr, not the official
app. Bundle identifiers, the App Group and the store path are unchanged, so an installed app keeps its
data, Health permissions and AltStore update path.

## Settings on iOS 17 and 18

- **Every Settings page opens again.** 12.1.1 made the Settings overview open on iOS 17 and 18, but
  tapping any row then froze the app until it was closed. iOS 26 was not affected. Reproduced on an
  iOS 17.5 simulator with a test that taps every Settings row: the Settings screen read a system value
  for opening links, and once a page was open above the overview, iOS 17 re-rendered the overview about
  a hundred times a second. That read now sits in the one button that needs it. All 17 Settings pages
  open on iOS 17.5, and a tester on iOS 18 confirmed the fix on an iPhone.
- **Dashboard layout from Settings.** The dashboard layout editor opened a navigation stack of its own
  inside Settings, a shape older iOS versions handle badly. It now uses the Settings stack; the
  long-press sheet on the dashboard keeps its own.
- A source test now fails if the Settings screen reads the link value again.

## AgeLess

- **The More row opens the details directly.** AgeLess in More › Health & Body showed the Health tab's
  card, and the details needed a second tap. With a week to show, the row now opens the detail page
  itself. Without one it still shows the card, which says why.

Analysis migration required: no. Nothing in this release changes how values are computed.
